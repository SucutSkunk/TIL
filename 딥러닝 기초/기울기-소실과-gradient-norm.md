# TIL: Gradient Norm을 하한(0.01)까지 키우면 기울기 소실이 해결될까?

## 질문
Gradient Norm을 계산해서 0.01보다 작으면 0.01이 되도록 키우면 기울기 소실을 해결할 수 있지 않을까?

## 결론
가능은 하지만, 기울기 소실의 해결책으로는 한계가 큽니다.
Gradient Clipping은 "상한"을 두어 큰 값을 줄이는 방법이고, 위 아이디어는 "하한"을 두어 작은 값을 키우는 방법입니다. 표준 기법으로 쓰이지 않는 데에는 이유가 있습니다.

## 아이디어 예시
```python
# 전체 Norm이 0.01보다 작으면 0.01이 되도록 같은 비율로 키우기
# Gradient = [0.003, 0.004]  ->  Norm = 0.005
# 배율 = 0.01 / 0.005 = 2
# 새로운 Gradient = [0.006, 0.008]  ->  Norm = 0.01
```

## 한계 4가지

### 1. 수렴과 소실을 구분할 수 없음
- Gradient가 작은 이유가 소실이 아니라, 손실의 최솟값에 가까워졌기 때문일 수도 있음
- 이때 Norm을 강제로 키우면 최솟값 주변에서 계속 흔들려 수렴하지 못할 수 있음

### 2. 전체 Norm으로는 레이어별 소실이 가려짐
- 소실은 보통 앞쪽 레이어에서만 발생함
- 전체 Norm은 Gradient가 큰 레이어에 좌우됨
- 예: 뒤쪽 레이어 Norm이 5, 앞쪽 레이어 Norm이 0.0001이면 전체 Norm은 약 5라서 하한(0.01)에 걸리지 않고, 앞쪽 레이어는 여전히 학습되지 않음
- 레이어별로 하한을 적용하면 완화되지만, 레이어마다 기준값을 정해야 함

### 3. Gradient가 0이면 키울 수 없음
- Dead ReLU처럼 Gradient가 정확히 0이면 몇 배를 곱해도 0

### 4. 잡음도 함께 증폭됨
- Gradient가 거의 0일 때는 방향 정보도 부정확할 수 있음
- 이를 키우면 부정확한 방향으로 큰 업데이트가 일어날 수 있음

## 참고: 비슷한 효과를 내는 방법
Adam, RMSProp 같은 Optimizer는 파라미터별로 Gradient의 크기를 정규화하여 업데이트합니다.
- Gradient가 꾸준히 작은 파라미터도 어느 정도 일정한 크기로 업데이트됨
- 다만 소실의 근본 원인을 없애는 것은 아님(역전파에서 신호가 약해지는 구조는 그대로)
- 따라서 활성화 함수(ReLU 계열)와 초기화(Xavier/He) 개선이 여전히 필요

## 정리
| 구분 | Gradient Clipping | 하한까지 키우기 |
| --- | --- | --- |
| 목적 | 큰 Gradient 제한 | 작은 Gradient 증폭 |
| 대응 문제 | 기울기 폭주 | 기울기 소실(한계 있음) |
| 표준 기법 여부 | 널리 사용됨 | 일반적이지 않음 |

## 핵심 한 줄
Gradient Norm이 작다는 사실만으로 소실이라고 단정할 수 없고, 단순히 키우는 것은 소실의 원인을 해결하지 못합니다. 학습 손실과 레이어별 Gradient Norm의 추세를 함께 확인해야 합니다.
