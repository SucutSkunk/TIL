# `<br>`, `&nbsp;` 정리

## 1. 줄 띄우기 방법과 GitHub 적용 여부

| 방법 | 적용 여부 | 비고 |
|---|---|---|
| 빈 줄 여러 개 | 적용 안 됨 | 하나로 합쳐짐 |
| `<br>` | 적용됨 | 단독 사용 시 앞뒤로 빈 줄 필요 |
| `&nbsp;` | 적용됨 | 단독 사용 시 앞뒤로 빈 줄 필요 |
| `---` | 적용됨 | 구분선이 생김 |

## 2. `<br>`과 `&nbsp;`의 차이

| 구분 | `<br>` | `&nbsp;` |
|---|---|---|
| 정체 | HTML 태그 | HTML 문자 엔티티 |
| 역할 | 줄을 강제로 바꿈 | 공백 글자 하나를 넣음 |
| 특징 | 연속으로 쓰면 줄이 늘어남 | 연속으로 써도 합쳐지지 않음, 들여쓰기 흉내에 사용 |

### 이름의 유래

- `<br>`: **br**eak, 정확히는 line break(줄 끊기)
- `&nbsp;`: **n**on-**b**reaking **sp**ace(줄바꿈이 일어나지 않는 공백). `&`와 `;`는 특수 문자 코드를 나타내는 표시

## 3. 사용 시 주의사항

- 단독 줄로 쓸 때는 **앞뒤로 빈 줄을 한 줄씩** 넣어야 합니다.
- `<br>` 앞에 공백이 들어가거나, 빈 줄 없이 목록 바로 아래에 붙이면 뒤따르는 `>`, `---`, `###` 같은 문법이 깨져 일반 텍스트로 합쳐질 수 있습니다.
- 글자 바로 아래에 `---`가 붙어 있으면 그 글자가 제목(Setext 헤딩)으로 바뀝니다. `---` 위에는 빈 줄을 두어야 합니다.

## 4. 응용: 줄 낭비 없이 한 줄 띄우기

```markdown
- ***결정계수***에 대해 설명해주세요.<br>&nbsp;
> 회귀선의 기울기가 가파르다고 해서 ...
```

목록 항목 끝에 `<br>&nbsp;`를 붙이면 소스 줄 수를 늘리지 않고 한 줄 간격을 만들 수 있습니다. 더 띄우고 싶으면 `<br>&nbsp;<br>&nbsp;`처럼 이어 붙입니다.
