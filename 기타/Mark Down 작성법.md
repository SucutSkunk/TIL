## 1. 줄 띄우기 방법과 GitHub 적용 여부

| 방법 | 적용 여부 | 비고 |
|---|---|---|
| 빈 줄 여러 개 | 적용 안 됨 | 하나로 합쳐짐 |
| `<br>` | 적용됨 | 단독 사용 시 앞뒤로 빈 줄 필요 |
| `&nbsp;` | 적용됨 | 단독 사용 시 앞뒤로 빈 줄 필요 |
| `---` | 적용됨 | 구분선이 생김 |

## 2. `<br>`과 `&nbsp;`의 차이

| 구분 | `<br>` | `&nbsp;` |
|---|---|---|
| 정체 | HTML 태그 | HTML 문자 엔티티 |
| 역할 | 줄을 강제로 바꿈 | 공백 글자 하나를 넣음 |
| 특징 | 연속으로 쓰면 줄이 늘어남 | 연속으로 써도 합쳐지지 않음, 들여쓰기 흉내에 사용 |

### 이름의 유래

- `<br>`: **br**eak, 정확히는 line break(줄 끊기)
- `&nbsp;`: **n**on-**b**reaking **sp**ace(줄바꿈이 일어나지 않는 공백). `&`와 `;`는 특수 문자 코드를 나타내는 표시

## 3. 사용 시 주의사항

- 단독 줄로 쓸 때는 **앞뒤로 빈 줄을 한 줄씩** 넣어야 합니다.
- `<br>` 앞에 공백이 있거나, 목록 바로 아래에 빈 줄 없이 붙이면 뒤따르는 `>`, `---`, `###` 같은 문법이 깨져 일반 텍스트로 합쳐질 수 있습니다.
- 글자 바로 아래에 `---`를 붙이면 그 글자가 제목(Setext 헤딩)으로 바뀝니다. `---` 위에는 반드시 빈 줄을 두어야 합니다.

## 4. 응용: 줄 낭비 없이 한 줄 띄우기

소스 줄 수를 늘리지 않고 한 줄 간격을 만들려면 목록 항목 끝에 `<br>&nbsp;`를 붙입니다.

```markdown
- ***결정계수***에 대해 설명해주세요.<br>&nbsp;
> 회귀선의 기울기가 가파르다고 해서 ...
```

더 띄우고 싶으면 `<br>&nbsp;<br>&nbsp;`처럼 이어 붙입니다.

## 5. 화살표 예쁘게 넣기

HTML 엔티티를 사용하면 직접 입력하기 어려운 화살표도 넣을 수 있습니다.

| 결과 | 엔티티 | 용도 |
|---|---|---|
| → | `&rarr;` | 일반적인 흐름, 순서 |
| ← | `&larr;` | 왼쪽 방향 |
| ⇒ | `&rArr;` | 결과, 함의(이중선) |
| ↔ | `&harr;` | 양방향 |
| ⟶ | `&#10230;` | 긴 화살표 |

### 주의사항

- 코드 블록(백틱) 안에서는 엔티티가 변환되지 않고 `&rarr;`처럼 그대로 표시됩니다. 변환된 화살표가 필요하면 코드 블록 밖에서 사용해야 합니다.
- 표 안에서 엔티티 자체를 보여 주려면 위 표처럼 백틱으로 감싸야 합니다.
